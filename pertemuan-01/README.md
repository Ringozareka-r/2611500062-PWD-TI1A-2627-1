## 1. Konsep Dasar Pemrograman Web

Pemrograman web adalah proses membuat website yang dapat dibuka melalui browser seperti Chrome atau Edge.

Dalam membuat website, ada beberapa teknologi yang memiliki fungsi berbeda:

* **HTML** → untuk membuat struktur dan isi website.
* **CSS** → untuk mengatur tampilan website.
* **JavaScript** → untuk membuat website lebih interaktif.
* **PHP** → untuk mengolah data di server.
* **MySQL** → untuk menyimpan data.

Jadi, setiap teknologi memiliki tugas masing-masing dan dapat bekerja sama untuk membuat sebuah website.
