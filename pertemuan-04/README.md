# Pertemuan 4 - CSS3 Layout dan Responsive Web Design

## Pengembangan
- Perubahan yang dilakukan:
  - Memisahkan CSS dari `index.html` ke dalam `style.css`.
  - Menerapkan CSS Box Model pada elemen halaman.
  - Menerapkan Flexbox pada navigasi.
  - Menerapkan CSS Grid pada tata letak utama.
  - Menerapkan desain web responsif dengan pendekatan mobile-first.
  - Menyesuaikan navigasi dan tata letak untuk perangkat bergerak dan desktop.

- Commit dan push GitHub:
  - Pengembangan dilakukan secara bertahap menggunakan Git.
  - Perubahan telah di-commit dan di-push ke repository GitHub.

## Pengujian
- Perangkat bergerak:
  - Navigasi tampil secara vertikal.
  - Tata letak berubah menjadi satu kolom.
  - Gambar dan konten menyesuaikan ukuran viewport.
  - Tidak terdapat galat tata letak yang mengganggu tampilan.

- Desktop:
  - Ukuran viewport: 1280 × 720.
  - Navigasi tampil secara horizontal.
  - Bagian Beranda dan Tentang Saya tampil dalam dua kolom.
  - Bagian Kontak membentang pada seluruh lebar halaman.
  - Tidak terdapat galat tata letak yang mengganggu tampilan.

- Galat dan perbaikan:
  - Tidak ditemukan galat tata letak setelah dilakukan pengujian pada perangkat bergerak dan desktop.

- Validasi CSS:
  - File `style.css` divalidasi menggunakan W3C CSS Validation Service.
  - Hasil validasi: No Error Found.
  - Tidak terdapat error CSS yang perlu diperbaiki.
