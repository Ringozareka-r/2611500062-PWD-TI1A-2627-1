# Pertemuan 4 - CSS3 Layout dan Responsive Web Design

## Pengembangan

**Perubahan yang dilakukan:**
- Memisahkan CSS dari `index.html` ke dalam `style.css`.
- Menerapkan CSS Box Model pada elemen halaman.
- Menerapkan Flexbox pada navigasi.
- Menerapkan CSS Grid pada tata letak utama.
- Menerapkan desain web responsif dengan pendekatan mobile-first.
- Menyesuaikan navigasi dan tata letak untuk perangkat bergerak dan desktop.

**Commit dan push GitHub:**
- Pengembangan dilakukan secara bertahap menggunakan Git.
- Perubahan telah di-commit dan di-push ke repository GitHub.
