# Latihan Pertemuan 9

Pada pertemuan 9, saya melakukan:

1. Menyalin artefak yang diberikan sebelumnya untuk digunakan kembali.
2. Mengubah nama dan NIM sesuai data mahasiswa.
3. Menambahkan file `fungsi.php` berisi fungsi `bersihkan()` dan `tebal()`, lalu memuatnya di `index.php` dengan `include`.
4. Menambahkan contoh perbedaan `echo` biasa dan `echo` dengan `bersihkan()`, serta contoh array biasa.
5. Mengganti penyimpanan session per variabel menjadi satu array asosiatif `$_SESSION["formData"]`.
6. Mengganti `htmlspecialchars()` pada hasil formulir menjadi `bersihkan()`.
7. Menampilkan hasil formulir menggunakan array `$labels` dan perulangan `foreach`.
